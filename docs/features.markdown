## Features

A Windows interface for Angband, with an experimental Angband 4.2.6 engine included.

### Character and equipment

Create a character and manage inventory, equipment, spells and shops through
dedicated panels.

### Dungeon map

Use mouse targeting and follow game events through visual effects on the map.

### Appearance and layout

Adjust themes, fonts and panel layout. Optional CRT effects change the look of
the display.

### Saves and settings

Saves and settings live outside the application folder. The engine owns the saves;
AnybandUI handles interface preferences.

### Engine selection

Choose from installed compatible engine packages. Angband derivatives need
source changes and a compatible adapter—see [Architecture]({{ '/architecture/' | relative_url }}).

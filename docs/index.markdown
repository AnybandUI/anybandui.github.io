## A graphical interface for Angband and its derivatives

Play Angband through a Windows interface with a dungeon map and dedicated panels
for your character, inventory, equipment, spells and shops.

Currently bundled with an **experimental Angband 4.2.6 engine**.
Angband derivatives are also a target, but need engine changes to work with AnybandUI.
